# DS Bot mobile

The DS Bot app for iOS and Android. It controls the Bot team that runs on your computer; nothing runs on the phone. The design is in [docs/plans/2026-10-24-mobile-app.md](../docs/plans/2026-10-24-mobile-app.md).

This is the first skeleton: it opens one screen and does not connect yet. The encrypted link to the computer is in [../link](../link); run `npm ci` there too before you build.

## Run

Needs Node 22 or later. iOS needs Xcode on macOS; Android needs the Android SDK and an emulator or a device. Expo Go is not supported, because the app will use native modules.

```sh
npm ci
npm run ios          # build and open in the iOS Simulator
npm run android      # build and open in the Android emulator
npm run typecheck
```

Two bundles can be built side by side; both are chosen at bundle time:

  left drawer and opens on the last chat.
- `EXPO_PUBLIC_DSB_DEMO=1` — skips pairing and fills the app with a demo team.
  Only active when the flag is set while the bundle is built.

```sh
EXPO_PUBLIC_DSB_DEMO=1 npx expo start   # variant B, demo data
npx expo run:android --device <emulator>                    # native build when deps change
```

`ios/` and `android/` are generated by the build and are not committed.

## Release

- Android: `.github/workflows/release.yml` builds and signs the APK.
- iOS: the account items, the archive/upload steps and the failure guide are in
  [docs/plans/2026-11-13-ios-release.md](../docs/plans/2026-11-13-ios-release.md).
  With the Apple account variables set, `npm run ios:archive` archives and exports
  `ios/build/export/DSBot.ipa`; `sh scripts/ios-archive.sh --upload` also sends it to
  TestFlight. `mobile-ios` in `.github/workflows/test.yml` builds the iOS project for the
  simulator on every change, unsigned.

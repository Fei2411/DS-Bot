# 手机 App

- 日期：2026-10-24
- 相关：[愿景](../vision.zh.md)「独立应用」「数据留在用户自己的电脑上」、[桌面应用](2026-10-16-desktop-app.md)、[角色与权限](2026-10-07-roles-and-permissions.md)

## 为什么

用户离开电脑时，Bot 还在干活：要审批、要回答问题、要看结果、要再派活。手机 App 让用户在 iOS 和 Android 上远程操控自己电脑上的 DS Bot 团队。

取舍：

- **手机不跑 Agent。** Bot 的回合、工具、模型、记忆、聊天记录都留在电脑上，和桌面一样。手机只显示和操控。
- **连接自己做，借鉴 DSH Remote。** DSH Remote（MIT）的连接方式已经很成熟：端到端加密、电脑只往外连、直连失败自动走中转。我们用它的连接代码，改成 DS Bot 自己的协议，以后自己改进，不依赖它的插件、服务器和版本。用到的文件写进 `NOTICE`。
- **界面全部自己做。** Bot 团队、群聊、卡片的页面按 DS Bot 自己的设计做，不用通用的远程会话界面。
- **一套代码出两端。** Expo React Native，原生构建。

## 已定的行为

### 结构

| 部分 | 在哪里 | 做什么 |
|---|---|---|
| 手机 App | `mobile/` | iOS、Android 和浏览器导出。界面、团队状态、加密连接；浏览器有单独的只读为主操作允许列表 |
| Host 模块 | 电脑上，桌面应用内置；插件版也能用 | 认配对过的手机，把手机的操作交给 `ds-bot` 的 `api/bot`，和桌面界面用同一套操作 |
| 中转服务器 | 用户可自建，在配对地址中指定 | 配对信令、设备状态和密文中转；不提供系统推送 |

- 电脑只往外连，不需要公网 IP，不用开端口。
- 手机和电脑之间端到端加密（Noise IK）。当前连接使用 WebSocket 中转（`RelayTransport`），没有先尝试点对点直连的路径。
- 手机能用的操作和 `ds-bot` 同一个版本发布。`ds-bot` 加了操作，手机跟着能用。

### 配对和设备

- 电脑上显示二维码，手机扫码配对，不要账号。
- 第一次连上时记住电脑的身份。以后身份变了，手机拒绝连接并提示。
- 电脑上能看到已配对的手机，能移除。移除后这台手机立刻断开，不能再连。
- 手机的密钥存在系统钥匙串（iOS Keychain、Android Keystore）。

### 手机上能做什么

原生 App 提供下面的远程操作；不是桌面全部功能的镜像，本机配对管理和原生文件选择等入口不能远程调用。浏览器导出还会拒绝密钥、能力、安装更新等高权限操作。

| 页面 | 内容 |
|---|---|
| 电脑列表 | 已配对的电脑、在线状态、重新配对 |
| 团队 | Bot 和群的列表、搜索、未读；「需要你」：宿主收件箱清单（[收件箱](2026-11-25-inbox.md)）里的全部条目，按等你决定 / 需要修复 / Bot 的建议分组；连旧宿主时按团队状态算 |
| 私聊 | 消息、图片、更早的记录、Side chat、停止 Bot 的工作 |
| 群聊 | 消息、进度；停下群里的工作 |
| 审批、提问、卡片 | 选项和桌面一样；卡片能填、能回复 |
| Bot 和群 | 新建、编辑、复制、删除；设 Main Bot；模型、思考强度、权限预设；成员 Agent |
| 记忆 | 每个 Bot 和群的记忆：查看、问、忘记 |
| 密钥 | 回应 Bot 的密钥卡；在设置里新增、更新、删除。值只在加密连接里传，手机上不回显 |
| 连接器 | 连接、断开、重试 |
| 日程 | 新建、删除、查看 |
| 能力 | MCP、技能、能力包：查看、保存、批准、删除 |
| 模型服务商 | 新增、删除，填 key，选模型 |
| 工作文件夹 | 在文件夹列表里选；团队工作区 |
| Bot 浏览器 | 看画面、接管、交还、回应浏览器等待 |
| 用量和统计 | 查看 |
| 更新和诊断 | 查更新、装更新；看诊断日志、清理 |

- 只有必须在电脑本机做的事换了做法：选文件夹的系统对话框换成手机上的文件夹列表；Bot 浏览器还在电脑上跑，手机看画面、接管。
- 角色和权限和桌面一样，见[角色与权限](2026-10-07-roles-and-permissions.md)。

### 高权限操作

- 改密钥、模型服务商 key、连接器、能力、装更新，每次要先在手机上解锁（Face ID、指纹或锁屏密码）。没解锁不发出。

### 同步

- 团队状态按版本号同步，只取变化的部分。
- App 在后台时默认停止前台状态轮询，回到前台时补齐；Android 开启后台模式时支持定时同步（`JobScheduler`）或实时保活（`remoteMessaging` 前台服务）。
- 断线时页面显示「已断开」，重连后补齐。写操作不自动重试，避免同一条消息发两次。

### 通知与离线推送（Android）

- **原生系统通知与分组通道**：区分「等你处理」（高优先级，宿主收件箱每出现一个新条目推一条：审批、提问、视图卡、密钥、连接器、邮件外发、电脑操控、浏览器接管、群目标、被卡住的 Bot、派活或群聊暂停、学习提议）、「回复与完成」（默认优先级，含 Bot 私聊回复、群消息与任务完成）与「后台连接」（静默低优先级）三个系统通道；点按通知通过 `dsbot://open` 直达对应 Bot、群聊或「等你处理」页，打开对应聊天时自动清除其未读通知。
- **应用内设置**：在「设置 → 通知」提供总开关、按事件类型开关（等你处理 / 回复与任务完成 / 群聊消息）、消息预览隐私开关、应用内横幅、系统通道入口、电池无限制入口与测试通知。
- **后台与杀进程送达**：支持「关闭 / 定时同步 / 实时保活」三档后台模式；客户端内置 UnifiedPush v2 接收器（无需 Google 服务即可配合 ntfy 等分发器在杀进程状态下唤醒）。电脑端使用宿主静态私钥 + 临时 X25519 双 DH（HKDF-SHA256 + ChaCha20-Poly1305）端到端密封并认证通知载荷，中转服务器与推送分发器既看不到明文也无法伪造通知。

### 应用内自动更新（Android）

- 在「设置 → 应用更新」及启动节流检查（默认 4 小时一次，可关）查询 GitHub Releases（支持 ETag、`releases/latest` 降级、Release 说明中的镜像链接及可选自定义 HTTPS 镜像源）。
- 仅当目标版本严格高于当前版本（正式版忽略预发布版）且校验值可信时提供下载；原生流式写入 `cacheDir/updates/` 同时计算 SHA-256 并严格比对 `SHA256SUMS.txt`（及 GitHub asset digest），校验失败自动删包并回退源站，绝不跳过校验。
- 通过独立 `FileProvider`（`${applicationId}.dsbot.apkprovider`）调起系统安装器；未授「允许安装未知应用」权限时引导至系统授权页，授权返回后继续安装。

### 安全

- 只接受配对过的手机。参数只能是普通 JSON 对象。
- Bot 发来的卡片是不可信内容：只按固定格式渲染，有深度和大小上限，不执行网页、脚本，不访问网络。

## 不做什么

- 不在手机上跑 Agent，不在手机上持久化团队数据和聊天记录；配对身份、通知游标和连接配置会保存，最新聊天页有内存缓存。
- 不做远程桌面和终端。

## 已知限制

- iOS 上架要 Apple 开发者账号，测试版走 TestFlight，不提供应用内自更新。Android 可以直接装 APK 并支持应用内检查、校验与安装。
- 电脑关机或睡眠时，手机连不上。
- Android 在厂商强杀（强制停止）后需依赖已安装的 UnifiedPush 分发器唤醒；未配置推送分发器时可通过「实时保活 + 电池无限制」或「定时同步」兜底。

# 头像动效

- 日期：2026-11-24
- 相关：形象重绘 PR #2168（本设计在其之上）
- 代码：`ds-bot/src/client/avatar/`（`models.js`、`sdf.js`、`mesh.js`、`silhouette.js`、`rig.js`、`face.js`、`clips.js`、`states.js`、`engine.js`、`render.js`、`live.js`）、`ds-bot/src/client/mark.js`
- 调试台：`ds-bot/dev/avatar-studio.html`（在仓库根起静态服务后打开）

## 为什么

旧动画是一组 CSS 关键帧：整张平面图上下晃、左右摆、眼睛缩放。平面剪影不会转身，所以「看你」「歪头」「转圈」都只能是整图旋转或压扁，状态之间也没有过渡，读起来像贴纸在抖。

新形象（#2168）本来就是从 3D 模型以三分之四视角烘焙出来的平面图。让同一个模型在运行时动起来，就有真正的点头、歪头和转圈，静止时又和平面图完全重合。

但这些形象是按侧前方的一张平面图设计的：身体转过几度以上，就会露出扁平的侧面，两只眼挤到一边，像比目鱼。所以除了转圈，身体最多转 `TURN` = 5°（`clips.js`），「看」交给眼睛在脸上移动。

## 已定的行为

### 1. 一个模型，两种画法

- 每个形象是一个有符号距离（SDF）模型，定义在 `models.js`，烘焙器 `dev/characters.mjs` 和运行时共用这一份，平面图与活头像不会走样。
- 没动过的头像只显示 `characters.js` 的平面 SVG，不建模型。头像第一次离开静止姿态时（进入状态、被摸、跟随指针、被戳、活泼档的眨眼），才把模型网格化（naive surface nets，网格点贴回表面并取 SDF 法线，按形状缓存），在原位叠一层 canvas，SVG 隐藏；之后这层保留到头像卸载，所以状态结束时能播回静止，不会跳回平面图。
- 构建按时间切成约 1ms 一步（`avatar/steps.js`，按计时不按工作量，所以慢机器和复杂形状也一样短），在 `requestIdleCallback` 里做：最多等 300ms，等不到空闲就强制做 5ms；没有 `requestIdleCallback` 时用短定时器，每片限 8ms。模型好之前动作先等着，好了从头播，不会在平面图上开始、canvas 接手时跳一下。
- 每帧把网格转到当前视角，取法线与视线垂直处的等值线作为轮廓（marching triangles），按非零环绕规则填充：洞（如环形）保持空心，肢体叠加不留缝。网格的边只编号一次，每帧只填复用的类型数组；一帧约 0.04–0.2ms（网格越细越多，鲸鱼最多）。
- 静止视角固定为 `VIEW = { yaw: 34, pitch: 16, roll: 10 }`，按平面图的规则归一化（长边占 100 单位盒的 92，居中），所以切换时不跳。
- 照片和插件画的形状没有模型，只做整体平移、旋转、压扁（`flatTransform`）。

### 2. 眼睛与表情

- 眼睛是贴在模型表面的胶囊，静止位置固定在表面上，随身体点头、歪头；转到背面时隐藏。投影后的宽高和倾角与烘焙器算法一致。
- 看向某处时，眼睛在画面里平移，大小和形状不变，不沿曲面滑到边上变扁。能走多远在建模型时一次量好（`rig.js` 的 `lookSteps`）：
  - 在 0.5 单位的网格上，把「身体减去贴花」标成可放眼睛的区域，肢体叠在身上也算身体。
  - 从眼睛轮廓上的每一点，向 16 个方向逐格推进，到离开该区域前 1.5 单位为止，两只眼取较小值，一起移动，不会斗鸡眼。
  - 量两张表：中性眼一张，最大眼（1.35 倍）一张；眼睛比中性大 8% 起就用大眼表（小眼在同中心的大眼之内，所以一定放得下）。
  - 相邻方向取最小值，两个方向之间的凹口卡不住眼睛。
  - 很多形象的眼睛本来就靠脸的右侧，往右看空间小，就由身体轻微倾斜和平移来表现。
- `face.js` 定义 15 种表情：neutral、wide、surprised、focus、think、curious、content、sleepy、worried、determined、happy、asleep、wink、peek、dizzy。
  - 胶囊类由宽、高、偏移和上下眼睑（含倾角、下眼睑弧度）组成，任意两种平滑插值。
  - 带眼睑的眼睛是「胶囊 ∩ 上眼睑 ∩ 下眼睑」的二维距离场，用平滑交集（圆角约 0.6 眼宽）合成，再沿射线描出轮廓：没有直角，眼睑压到一侧时收成圆头，不会折叠。
  - 弧线类（开心、睡着、晕）换入换出时藏在一次眨眼后。
- 眨眼把眼睛压成约眼宽 1/5 的缝，不完全消失。

### 3. 片段与状态

- 片段（`clips.js`）是多轨关键帧：位移、转身（不超过 `TURN`，转圈除外）、点头、歪头、压扁、缩放、眼神、眼睑。每轨首尾为 0（转圈为 360 的整数倍），叠加在姿态上，所以任意片段可以随时打断，0.25 秒淡出。
- 片段可左右镜像、按 Bot 的种子随机抖动，可带表情、眨眼、点缀事件；转圈类标为必须播完。
- 状态（`states.js`）= 姿态 + 表情 + 进入片段 + 循环动作袋（带权重和间隔）+ 小尺寸专用袋 + 活泼档专用袋 + 点缀。抽取时不连续重复同一片段；每个 Bot 用自己 id 的种子，所以一排 Bot 不会同步。
- 姿态由逐通道弹簧带动（头比眼慢，压扁更松），不套界面弹簧常量。
- 状态一览见 [UI 设计标准 §8](../design/ui-standard.md)。`orbit`（群里转发）映射为 `relaying`。

### 4. 交互

- 跟随指针：眼睛在脸上看向指针，身体只朝指针轻微倾斜、平移；指针在头像上时眼睛正视你。所有跟随的头像共用 `live.js` 的一个 pointermove 监听，每帧先读全部位置再更新引擎；同一位置不重复计算。
- 抚摸：指针停在侧栏行、关于页头像（`.bt-pet-zone`）上时眯眼笑，身体靠向手的一侧并微微压低，不转身。
- 戳：可戳的头像点一下弹一下；1.6 秒内连点依次升级为转一圈、转两圈、晕。转圈时从身后撒出彩带和纸片：
  - 颜色是本形象的颜色加几种主题色，随明暗主题变化；
  - 约 1.7 秒落完，只在画布留白内；
  - 小头像（<28px）和精简动效下不出现（精简时连点只弹不转）。
- 睡着偷看：活泼档打盹后，隔 7–14 秒偷看一次。一只眼眯开，先看一侧，再看你，然后赶紧闭上。之后每次间隔乘 1.7，越睡越沉。窗口在休息中也会偷看：那正是有人在看屏幕、但没有操作的时候。

### 5. 档位、减少动态与省电

| 设置 | 效果 |
|---|---|
| 头像动画「安静」 | 只有状态动作（含状态里的眨眼）；不跟随、不抚摸、不戳 |
| 「正常」（默认） | 加抚摸、戳、跟随指针 |
| 「活泼」 | 再加空闲眨眼、扫视、小动作、等你回答时反复招呼、长时间无输入后打盹（睡着会偷看） |
| 界面动效「精简」 | 只播一次性动作和表情；不循环（包括状态里的眨眼、思考的点）、不跟随 |
| 界面动效「无」/ 系统减少动态效果 | 不动，表情原地切换 |

- 尺寸分级：≥48px 全部；28–47px 不画持续点缀（思考的点、睡觉的 z）；<28px 用小动作袋、幅度减小、不画点缀、最多 30fps。
- 共用时钟：只在有头像在动时跑 `requestAnimationFrame`，否则定时到下一次动作；页面隐藏或头像离开视口时跳过；30 秒无输入后做完当前动作就停（与 `motion-rest.js` 同一阈值；指针停在头像上也一样，「完成」照样回到「空闲」）；活泼档 150 秒无输入后打盹，有输入即醒。最后一个头像卸载时，监听、观察器和定时器全部移除。
- 颜色读主题 CSS 变量（旧色名按 `inkName` 映射）。一个 MutationObserver 只盯 `data-ds-dark-theme`、`data-bt-motion`、`data-bt-effects`，值真的变了才刷新；切聊天时 body 上别的样式变化不会让头像重画。

## 不做什么

- 不再写头像 CSS 关键帧；新动作只加片段和状态权重。
- 不在运行时用 WebGL 或光照：形象是纯平面剪影，只要轮廓和眼睛。
- 不模仿任何第三方产品的形象或动作。
- 桌面端启动窗口不用这套引擎：它要在应用加载前就画出来，仍用自己的轻量鲸鱼动画（`app/src/start/whale.js`）。它的眼睛遮罩（跟随组、开心弧线眼）由 `app/scripts/start-assets.mjs` 从鲸鱼的眼睛数据生成，不依赖头像的 SVG 结构。
- 手机端暂时仍显示静态平面图（引擎不依赖 DOM，`render.js` 的 `pathsOf` 可直接给 react-native-svg 用）。

## 已知限制

- 网格精度按尺寸取值（鲸鱼尾鳍较薄，单独用更细的格），极小尺寸下细节由平面图规则保证，不再细化。
- JSDOM 等没有 2D canvas 的环境会退回到整图变换；测试据此覆盖引擎逻辑，绘制在浏览器里核对。

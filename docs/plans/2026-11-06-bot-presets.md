# 每个 Bot 的 Agent 预设

- 日期：2026-11-06
- 相关：#1039；预设归 DS Bot 所有、不跟随 DSH「新任务默认」的既定立场见 [Bot 运行配置](2026-10-10-bot-runtime.md)；DSH 侧限制见 [DSH 让步总账](2026-10-13-dsh-concessions.md) C13
- 代码：`ds-bot/src/host/roster.js`（预设目录、兼容检查、存取）、`parts.js`（换预设换段与空闲时补换）、`channel.js`（`presets` 操作）、`store.js`（数据清理）；界面在 `src/client/agent-preset.js`、`agent-preset-menu.js`、`create-bot.js`、`bot-settings.js`

## 为什么

DSH 的 Agent 预设决定一个 Session 有哪些工具、提示段和技能。预设是全局或按会话选的：用户给 DSH 选的预设，以前不适用于 Bot——Bot 会话一律固定用 `standard`，用户自定义的组合进不了 Bot（C13）。

每个 Bot 该跑在什么 harness 上属于它自己，这个选择和模型一样，是该 Bot 的设定，不是用户的 DSH 全局设定。所以给一个 Bot 选预设：默认仍是 `standard`，但可以显式换成这个 profile 提供的另一个预设，比如为某个 Bot 装上另一套工具组合。

## 已定的行为

### 选择和存储

- `Bot.agentPreset` 存预设 id（字符串）。没存这一字段的 Bot 沿用原有默认：这个 DSH 提供**可用且与 Bot 兼容**的 `standard` 时显式用 `standard`；否则交给 DSH 决定——用注册表自己的默认 id（发布版 `standard`，或用户在 DSH 设置里改的 profile 默认），不是 DS Bot 替它另选一个。
- 那个 DSH 默认也要过兼容检查：一个已知但不兼容的默认，会让这个 Bot 的**新会话建不起来**（明确报错，让用户去给 Bot 选一个预设），而不是悄悄开一个没有 Bot 身份的会话。DSH 给不出默认 id、或没有可用的检查手段时，才让 DSH 自己组装，保持原样。
- 预设是**用户专属设置**：只有用户能在建 Bot 表单和 Bot 设置里选。`create_bot` 不设它；`update_bot` 带 `agentPreset` 的请求被拒绝，Bot 不能给自己或别的 Bot 换 harness。
- 显式选中的预设必须在这个 DSH 的预设目录里、能启动（没有 `broken`）、并且**与 Bot 兼容**。兼容的判定不读预设的声明：DS Bot 用 DSH 的公开 API 取一次这个预设的作用域（`agentPresets.acquireScope`），再组装一次提示词（`systemPrompt.assemble`），看 Bot 自己的身份段（`bot-identity`）还在不在——完整 persona 会顶掉 DS Bot 注入的身份、指令和 Main Bot 规则（官方 `minimal` 就是这样），段没了就不兼容。没有这两个公开 API 的 DSH 答不了这个检查，按原样处理；检查本身出错时宁可拒绝，也不拿一个可能顶掉 Bot 身份的预设。不兼容的预设和 `broken` 一样不可选，目录里也标出来，带原因。
- 这个检查**不缓存**：同一个 id 下的组成可能随时变（用户在 DSH 里改了插件），所以每次建会话、每次判断都重新查一遍，没有 60 秒之类的时间窗。
- 用户把显式选择清回默认时，Bot 上记一个内部标记 `agentPresetDefault`（只有 `true` 一个值）：它表示「默认是用户自己挑的」，好让换段失败后在下一轮补上。这个标记**不出现在 Bot 的对外记录里**（`api/bot` 的 `state` 不带它），也不是一个能设的字段；它只跟着 `state.json` 存，坏值（不是 `true`）或和显式 id 同时存在的，在载入时丢掉。清空时另存 `agentPresetDefaultPending`，记录当前私聊和群会话的 id：宿主无法给出默认 id 或兼容检查 API 时，这些段仍会换到由 DSH 默认组成的新段；失败后保留待办供重启重试，成功后移除对应 id，避免重复换段。从没设过预设的旧 Bot 没有这些标记，保留它那些段原来的预设。
- 已存的预设后来被目录拿掉或变 `broken`：Bot 保持原样，现有段继续跑，设置界面把它标成 missing / broken，提示用户另选；DS Bot 不替它换预设。
- 复制一个 Bot 带上它的 `agentPreset`；原预设已失效时复制失败并报错，而不是让副本换一套组成。
- `state.json` 里坏掉的 `agentPreset` 值（非字符串或空白）在载入时丢弃，回到默认，而不是让每个会话都建不起来。

### 会话一致

- 一个 Session 保留它创建时的预设（DSH 语义）。预设存在 Bot 上，所以它名下的每个 Session——私聊首段、换段新段、它在每个群里的成员会话、进群时新开的那一段——都在建的时候取这个 Bot 当时的预设。
- 群自己的中继会话不是哪个 Bot 的：它按默认走（可用的 `standard`，否则 DSH 的默认），不随成员的预设变。
- 群成员会话不需要 `group_relay`：那是**群自己的中继会话**才有的调用；成员会话是 Bot 自己的会话，跑 Bot 的那套工具。PTC 这类只允许 `run_code` 的预设下，群的中继仍按 `run_code` 接力（既有兼容路径，C1、#37）。

### 换预设

- 换一个 Bot 的预设后，DS Bot **主动**给这个 Bot 名下的每个会话排一次换段（私聊和它在每个群里已有的成员会话），换段在它们各自空闲时发生：Session 的预设改不了，只能换段。走既有的安全机制（parts.js）：旧段整段保留可读，交接包写明原因是「agent preset changed」，换段期间到达和已排队的消息随新段继续，不丢消息；换段失败时把输入放回旧段继续，不留半截。
- 换段没成功也不算数：每次会话进入空闲状态都会看这一段记的预设和 Bot 现在的选择是否一致，不一致就补一次换段。正在跑的整轮任务继续完成，空闲前不登记换段，避免下一步被换段守卫接管。用户显式清回默认的 Bot（`agentPresetDefault`）也走这条补的路径。
- 新段照常带上这个 Bot 的模型、思考强度、权限预设和能力，不被预设冲掉。
- 群自己的中继会话不是哪个 Bot 的：按默认走，不换。
- 一次换段还没走完又改了预设：正在换的那一段不打断，它建成新段时读的是**当时**最新的选择，所以通常直接落在最新的选择上，不必再换一次；万一新段仍不是最新的，下次空闲时会补一次。等待当前轮次结束期间改回原预设，不再换段。最后一轮失败时，先保留当前段的修复和重试入口；用户恢复任务、成功结束一轮后再应用保存的预设，避免交接确认误清失败状态。

### 安全边界

- 预设是组成，不是权限：Bot 的权限预设照旧单独管，预设不放宽它。
- Bot 拿掉的 DSH 工具（提问、goal、委派/子代理、Agent Teams 工具）靠 DS Bot 自己的 restrict、组装过滤和 guard 三道挡住（[Bot 运行配置](2026-10-10-bot-runtime.md)），执行仍会被 guard 拒绝，Bot 自己的角色和硬限制也照旧。但这套挡法只覆盖 DS Bot 认识的那三类：DSH 的公开接口不能按会话过滤**预设自带的**工具，完整的逐 Bot 工具过滤仍受 DSH 公开 API 限制、不在本提案范围内，所以自定义预设带来的同名工具，模型可能真的拿到。用户不能用预设解除「Bot 不派子代理、不用阻塞提问」这些硬限制，但预设也不是一个能把工具完全藏起来的沙箱——当选的预设必须当整体信任。
- DSH 的预设不是安全沙箱：预设声明里的插件能跑宿主代码。给 Bot 选一个预设，等于把这套组成交给它的会话；选不认识的预设的风险和装一个插件同级，由用户在目录层面把关。

### 界面和通道

- `api/bot` 的 `presets` 操作（只读，另一个 dsh 持有团队时也可答）返回 `{ presets: [{ id, name?, description?, broken? }] }`：这个 profile 的预设目录；坏的、以及与 Bot 不兼容的，留在列表里带原因，让选择器能显示但禁选。
- `create-bot` / `update-bot` 的 payload 接受 `agentPreset`：字符串 id 或 `null`（清掉显式选择，回到默认）。未提供即不改。`null` 表示用户自己挑了默认，Bot 上因此记下内部标记 `agentPresetDefault`（不对外暴露，见上）。
- 建 Bot 表单和 Bot 设置里有一个 Agent preset 选择器：第一项是默认项，后面是目录里每个预设。第一项的名字和提示**跟着目录走**：目录里有可用的 `standard` 时叫「Default (Standard)」，没有时叫「Default (DSH default)」；目录还没读到时第一项只写「Default」，Bot 设置那一行显示「Loading…」，读到之后才定名。选默认项等于清掉显式选择。`broken`（含不兼容）的禁选并显示原因；已选但不在目录里的显示为「Missing preset」，并带着原来的 id，不静默换成别的预设。选择器打开时重新取一次目录。
- 选择器只在 DSH 模型运行方式下显示；本地 Agent CLI 使用自己的组成。切换到本地 CLI 时保留 Bot 已存的 DSH 预设，但不应用、不校验它，也不因它触发换段；承载 CLI 的 DSH 会话沿用默认组成来提供团队工具。切回模型运行方式后继续使用保存的选择。

## 不做什么

- 不给 Bot 工具（`create_bot` / `update_bot`）开放预设参数。
- 不让预设改变 Bot 已有的模型、思考强度、权限、能力或工作文件夹；互不推导。
- 不给群设预设：预设按 Bot 记，群没有自己的 harness 选择；群的中继会话按默认走。
- 不为了换预设中断正在跑的回合：等空闲换段；中途到达的消息照常排队交接。

## 已知限制

- DSH 公开接口不能按会话过滤预设自带的工具，完整的逐 Bot 工具过滤仍受 DSH 公开 API 限制、不在本提案范围内：预设给 Bot 会话加的工具如果不在 DS Bot 自己的隐藏/拒绝名单里，模型会真的拿到它们。当选的预设必须当整体信任。
- 目录在另一个 dsh 改过时，已打开的界面里显示的是打开选择器时取到的快照。
- 内置预设的名称和说明读取 DSH 的当前语言文案；自定义预设保留目录中的名称和说明，DS Bot 不维护别名。

# 桌面应用自己的界面

- 日期：2026-11-21
- 相关：[桌面应用](2026-10-16-desktop-app.md)（改了它「界面先用 DSH 的网页前端」一条）、[外观](2026-11-21-appearance.md)、[DSH 让步总账](2026-10-13-dsh-concessions.md)

## 为什么

桌面应用的窗口现在是 DSH 的网页前端，`ds-bot` 以插件的形式在里面。DS Bot 自己画侧栏、群聊、设置和各种卡片，但 Bot 私聊当前这一段的对话、工具卡片、右侧栏、窗口外框、深浅色和字号还是 DSH 画的。结果是：

- 很多地方只能让步（让步总账里桌面应用相关的条目）。
- 外观只管得到一半：DS Bot 的主题、背景和字体到不了 DSH 画的部分。
- DSH 网页前端启动时要激活全部界面插件，一个插件出错整页停住；它的模块格式和页面结构由 DSH 决定，还在变。

所以桌面应用的界面全部由 DS Bot 自己画。DSH 只在引擎里跑 Bot 的 Agent（循环、工具、模型、会话、MCP、技能、插件）。

2026-10-18 第一次做时停下了，原因是 DSH 网页前端已有的东西要一样样重做。这次先列出全部要做的东西（下面的对照清单），清单全部做完才发版。

## 已定的行为

### 结构

| 层 | 是什么 |
|---|---|
| 窗口里的网页 | DS Bot 自己的界面（`app/ui/`）：React，Vite 打包，标准 ESM。画面由 `ds-bot/src/client/` 里的 Bot 界面组件组成，和插件版共用 |
| 地基 | DS Bot 自己写：路由和按页加载、界面插件运行时、连接、语言、快捷键、弹层 |
| 引擎接口 | `ds-bot` 的 `api/bot` 通道和实时推送 `api/bot/feed`。网页不直接调用 DSH 的服务 |
| 引擎 | DSH + `ds-bot` 的引擎部分 + 用户装的引擎插件。profile 里不加载 DSH 网页前端的任何一行 |

插件版不变：`ds-bot` 仍然装在 DSH Desktop、DSH Web 里，用 DSH 的网页前端和插槽。两种形态功能一样，做法可以不同。

### 界面插件

- 写法照 Cordis：插件提供和使用服务、声明依赖、每个注册都能撤销、界面靠插槽组合。
- 和 DSH 重叠的位置用 DSH 的插槽名和数据：工具卡片 `tool.call.toolview`、对话节点 `conversation.chat.node`、右侧栏标签 `sidebar.right.pane.tab`、设置 `settings.section` / `settings.general.item`、全局弹层 `shell.overlay`。DSH 的界面插件换打包方式、接上这些插槽就能迁过来。
- 按页面加载。一个插件出错，只有它那一块显示错误和「重试」，其他部分照常。
- 主题也是一种插件（见 [外观](2026-11-21-appearance.md)）。

### 对话

- 私聊和群聊用同一套转写。每一段（包括正在进行的这一段）都由 DS Bot 画。
- 引擎把 DSH 会话事件按顺序推给网页：回复文字、思考、工具调用和结果、审批、提问、附件。网页断线重连后从最后收到的序号接着读，不整段重读。
- 工具卡片：先找注册在 `tool.call.toolview` 的卡片，没有就用通用卡片（工具名、参数、结果，长结果折叠）。

### 经典 Agent 模式

- 桌面应用里，经典模式是一份普通会话列表，打开的会话用同一套对话界面。
- 从 Bot 模式进经典模式、再回来，两边的位置都保留。

### 窗口外框

- 窗口外框由应用自己画：macOS 无边框，红绿灯在侧栏上；Windows 无边框，系统按钮在对话区上，Windows 11 用 Mica。
- 不显示 DSH 的「预览版说明」。

## 对照清单

每一项都要在自己的界面里有，行为不比插件版里 DSH 画的差，才能发版。

| 块 | 项 |
|---|---|
| 地基 | 路由和按页加载；界面插件运行时和上面的兼容插槽；插件出错的隔离和重试（清失败导入缓存并在设置 → 插件提供重试）；8 种语言；快捷键自定义和速查（见 [快捷键](2026-11-25-shortcuts.md)）；弹层优先级栈和 Esc；窄窗口抽屉（`<= 768px` 到 `508px` 单一按钮切换）；只读窗口；断线重连 |
| 对话 | Markdown、代码块和复制；思考；工具卡片（通用卡 + 命令、改文件和差异、读文件、搜索、浏览器、电脑操控、Office、子代理、计划、后台任务、技能）；审批；提问；附件和图片；交付物和改动卡；文件引用；回复反馈；长回复阅读胶囊；凭据遮挡 |
| 输入 | 输入框和没发出的文字；`@` 和 `/` 菜单；语音；附件上传和拖放；模型和思考强度；权限档；排队和插话 |
| 右侧栏 | 文件树（实时监听变更并保留展开与滚动、右键菜单）、终端、文档预览（Excel 多工作表表格视图、CSV/TSV 表格、Office 转 PDF、Markdown、代码、图片、PDF、HTML、文本）、浏览器（Bot 模式与经典模式共用） |
| 设置 | 账号（登录、退出、账单页）；插件（已装、启用、停用、安装、窗口插件出错重试）；Agent 循环与 Shell（显式保存/放弃/恢复默认）；网页搜索（按已注册提供方选择）；子代理（仅经典模式显示，Bot 模式按策略关闭）；会话日志上传（显示保存结果与错误）；Agent 预设；归档的会话；深浅色、字体和字号 |
| 外框 | 窗口外框和拖动；窗口材质开关（设了背景时不用材质）；启动页到团队窗口的衔接；更新提示 |
| 经典模式 | 会话列表、新建、重命名、归档；同一套对话；右侧栏文件树、终端、预览与浏览器；快捷键速查隐藏仅 Bot 模式可用的项 |

## 不做什么

- 不做 DSH 界面插件的「无缝」兼容层：DSH 网页前端的插件格式和页面结构还在变。等它稳定了再评估。
- 桌面应用不保留切回 DSH 网页前端的开关：两套界面不能都维护好。

## 已知限制

- DSH 新增的界面功能不会自动出现在桌面应用里，要 DS Bot 自己做。

# 外观

- 日期：2026-11-21
- 相关：#1129（换主题时自定义颜色怎么办）、[桌面应用自己的界面](2026-11-21-own-frontend.md)、[消息布局和宽度](2026-10-22-message-layout.md)

## 为什么

以前能改的只有主题（4 套）、强调色、消息布局和宽度、动效。背景只能靠第三方皮肤插件；字体、深浅色和字号是 DSH 的设置，只在 DSH 画的部分起作用。用户想把界面改成自己的样子：背景、字体、颜色、形状都能改，改完在每台设备上一样。

取舍：

- 外观是一组变量（颜色、字体、圆角、间距、背景）。主题给默认值，用户的改动盖在上面。DS Bot 的每个表面都只用这些变量，所以改一处，全团队的界面一起变。
- 外观跟着团队存，所有设备（桌面、手机、网页远控）一样。
- 不拦用户：对比度不够时提示，不阻止保存。改坏了有「恢复默认外观」和安全外观两条退路。

## 已定的行为

### 存在哪

- 全部存在团队设置里，跟着团队同步。背景图存在数据位置的 `backgrounds/` 里，按内容的哈希命名，同一张图只存一份。没有地方再用的图，过 10 分钟后删掉；刚选的图在这之前不会被删。
- 主题文件可以导出、导入（`.json`）。导出时背景图一起放进文件。主题文件不带自定义样式表：别人的 CSS 能把界面画成误导人的样子，或把输入的内容发到外部地址。导入后，文件里没写的外观项（圆角、密度、背景、字体、字号、行高）回到默认，不和原来的混在一起；团队强调色让位给主题自己的强调色。

### 主题

- 内置 4 套主题：DeepSeek、Mono、Paper、Moonlight。每套都有浅色和深色。
- 自己的主题：在任一主题上改颜色，就存成一套自己的主题（「我的主题」，可改名、复制、删除）。换到内置主题时，自己的主题不清；换回来，改动还在。最多 32 套。
- 插件可以注册主题（`window.dshBot.registerTheme`）。
- 每套主题、每种模式 8 个颜色：强调色、背景色、文字色、侧栏、气泡、卡片、你的气泡、你的气泡文字。外观页先列前 3 个，每个都能用取色器或填 `#RRGGBB` 改；「更多颜色」展开其余 5 个。
- 改背景色或文字色时，侧栏、气泡、卡片跟着变：每个颜色在背景和文字之间的位置不变（按红绿蓝分别算），所以主题原来的色调（例如 Paper 的暖色侧栏）保留。你的气泡和它的文字原来接近文字色或背景色时跟着变，原来是主题自己的颜色（例如 Moonlight 的蓝色）时不变。在「更多颜色」里单独改的颜色，下次改背景色或文字色时也按这个规则跟着变。
- 强调色另有一个跨主题的选择（预设色或自定义），优先于主题里的强调色。在颜色里改强调色，就改回用主题的强调色。
- 文字和它所在表面的对比度低于 4.5:1 时，颜色旁边出现提示。

### 字体、形状和密度

- 圆角：0% 到 200%，100% 是设计默认值。圆形（头像、圆按钮）和胶囊形不变。
- 密度：紧凑、标准、宽松。改变侧栏行高、消息间距和卡片内边距。
- 字体：两种形态都由 DS Bot 管界面字体和代码字体。插件版里通过 DSH 文档化的字体变量（`--dsh-font-family-text`、`--dsh-font-family-code`）传给 DSH 画的部分，整页一起换。
- 字号和深浅色：桌面应用里，字号（12–20）、行高（1.3–2.0）和深浅色（浅色 / 深色 / 跟随系统）由 DS Bot 管。插件版里字号和深浅色仍是 DSH 的设置（DS Bot 的外观页里显示它们），因为整页其他部分也由它们决定。
- 字体从本机字体里选，也可以手填，多个字体用逗号隔开。每个字体名单独加引号写进样式，不能用 `/*`、`;`、`{`、`}`。另一台设备没有这个字体时，用系统默认字体。

### 背景

- 种类：无、纯色、渐变（两个颜色和角度）、图片。
- 图片：铺满、完整显示、平铺；模糊（0–40 px）；遮罩（0–80%，浅色模式是白色、深色模式是黑色）。PNG、JPEG、WebP、GIF，最大 12 MB。
- 表面不透明度：70%–100%。有背景时，背景上只铺一层主题主色（按这个不透明度），页面上的面板本身透明，侧栏留一点自己的颜色；设置、侧面板、停靠栏这类浮在页面上的东西保持近实心（94%）。只铺一层，是因为 DSH 把同一种底色的面板套了好几层，每层各自半透明会叠回几乎不透明。最低 70%：在纯白或纯黑的背景上，四套内置主题的文字对比度都不低于 5:1。
- 图片还没加载好、找不到或读不出来时，不画背景，面板保持原来的实心颜色。读不出来的图一分钟后再试。
- 桌面应用的窗口材质（Windows 11 的 Mica、macOS 的毛玻璃）开关，等桌面应用自己的窗口外框做好后再加；那时设了背景就不用窗口材质。
- 每个群、每个 Bot 的聊天可以在它的设置里单独设背景。打开这个聊天时，整个窗口的背景换成它自己的。

### 自定义样式表

- 外观页最下面可以写一段 CSS，最后加载，最大 64 KB。
- 「恢复默认外观」（点两次）：主题回到 DeepSeek，强调色、深浅色、字体、字号、行高、圆角、密度、背景和自定义样式表都回到默认。自己的主题保留。
- 安全外观：界面加载后 3 秒内按下 Shift 并单独按住一会儿（约 0.6 秒，中间没有按别的键），或按住 Shift 移动、点击鼠标（macOS 上按住的修饰键不会重复发按键事件），这个窗口就不加载背景和自定义样式表。打字时按 Shift 输入大写字母、带 Cmd / Ctrl / Alt 的快捷键都不算。打开后弹出提示，外观页最上面也写着，可以一键重新打开。只影响这个窗口（重新加载后仍然有效，关掉窗口就没了），不改设置。

## 不做什么

- 不按设备分别存外观。
- 不从网址下载背景图：只接受本机文件。

## 已知限制

- 插件版里，DSH 画的部分（Bot 私聊当前这一段、DSH 的设置页等）不跟着 DS Bot 的圆角和密度变；背景能透过它们的面板。
- 手机 App 和网页远控还不画背景和自己的主题。手机连接一条消息最大 4 MB，大于约 3 MB 的背景图到时要先缩小再传。

# 键盘快捷键系统

- 日期：2026-11-25
- 相关：#1694（`⌘1…9` 切换第 N 个 Bot）、[桌面应用自己的界面](2026-11-21-own-frontend.md)、[设置总控台](2026-11-22-settings-console.md)

## 为什么

桌面应用切到自写前端（`app/ui/`）后，不再加载 DSH 的快捷键模块；此前仅有 5 个写死的全局热键，无法自定义，也缺少高频工作流入口——尤其是切换 Bot / 经典 Agent 模式、打开收件箱、打开 Bot 浏览器与 `⌘1…9` 快速切对话。此外，焦点落在 Bot 浏览器（Electron `WebContentsView`）时，主窗口键盘监听收不到按键。

因此 DS Bot 建立统一的快捷键注册表、本地自定义持久化、「设置 → 通用 → 快捷键」管理页、实时速查弹窗与 Electron 浏览器视图透传，并把核心 Bot 命令同步注册到插件版的 DSH `shortcuts` 服务。

## 已定的行为

### 1. 默认快捷键（macOS 用 `⌘`，Windows/Linux 用 `Ctrl`）

| 分组 | 命令 ID | 默认键 | 行为 |
|---|---|---|---|
| 导航 | `palette` | `Mod + K` | 打开/关闭全局搜索与命令面板（设置页打开时保留给设置内搜索） |
| 导航 | `switch-surface` | `Mod + Shift + M` | 在 Bot 模式与经典 Agent 模式之间切换 |
| 导航 | `inbox` | `Mod + I` | 打开/关闭收件箱（收件箱挂载后自动生效） |
| 导航 | `prev-chat` / `next-chat` | `Mod + [` / `Mod + ]` | 按侧栏可见顺序切换上一个 / 下一个对话（经典模式切会话），切换后聚焦输入框 |
| 导航（1–9） | `switch-bot-1` … `switch-bot-9` | `Mod + 1` … `Mod + 9` | 跳到侧栏第 1–9 个可见对话（主 Bot → 未分组 → 展开分组，跳过已隐藏与折叠组），超出忽略，切换后聚焦输入框 |
| 面板 | `sidebar` | `Mod + \` | 展开 / 收起左侧栏（窄屏切换抽屉） |
| 面板 | `right-panel` | `Mod + Shift + \` | 展开 / 收起右侧栏 |
| 面板 | `browser` | `Mod + B` | 打开 / 收起当前 Bot（或主 Bot）的浏览器面板 |
| 面板 | `terminal` | `` Ctrl + ` `` | 打开 / 收起右侧工作区终端（终端内亦生效） |
| 面板 | `details` | `Mod + Shift + D` | 展开 / 收起当前 Bot 或群聊详情面板 |
| 面板 | `memory` | `Mod + Shift + E` | 打开 / 关闭当前 Bot 或群聊记忆弹窗 |
| 对话 | `new-chat` | `Mod + N` | Bot 模式打开新建对话；经典模式新建会话 |
| 对话 | `focus-composer` | `Mod + L` | 聚焦当前聊天输入框 |
| 对话 | `group-search` | `Mod + Shift + F` | 群聊内打开群搜索；其他视图打开命令面板 |
| 对话 | `stop-turn` | `Mod + .` | 停止当前运行中的 Bot / 群聊 / 经典 Agent 轮次（保留排队消息） |
| 应用 | `settings` | `Mod + ,` | 打开 / 关闭设置 |
| 应用 | `shortcuts` | `Mod + /` | 打开 / 关闭快捷键速查弹窗 |

固定交互快捷键（不可重绑）：发送（`Enter` / `Mod+Enter`）、换行（`Shift+Enter` / `Enter`）、`@` 提及、`/` 命令菜单、输入区 500ms 内连续双按 `Esc Esc` 停止当前生成、单按 `Esc` 关闭最上层浮层。

### 2. 自定义、冲突与持久化

- **存储**：桌面端按设备本地保存在 `localStorage`（`ds-bot.shortcuts.v1`），按平台桶（`mac` / `other`）隔离，仅保存覆盖项；`null` 表示解绑，恢复默认删除覆盖键。
- **校验**：拒绝纯修饰键、无修饰键的单字符（`F1–F12` 除外）以及核心系统/编辑键（`Mod + C/V/X/A/Z/Q/W/H`、`Esc`）。
- **冲突处理**：绑定与其他命令冲突时行内提示冲突命令名，提供「替换」一键转移或「取消」。
- **界面**：桌面应用在「设置 → 通用 → 快捷键」（锚点子页）提供过滤、录制（`Esc` 取消、`Backspace/Delete` 解绑）、单条复位与全部恢复默认；`⌘/` 速查弹窗动态跟随当前有效绑定并附「自定义」直达入口；`⌘K` 命令面板同步展示对应键帽。

### 3. 边界守卫与焦点穿透

- **输入法与录制**：IME 组合态（`isComposing`）和录制快捷键期间暂停全部全局分发。
- **终端透传**：Windows/Linux 焦点在 `.xterm` 时，纯 `Ctrl + <单键>` 放行给终端 PTY（显式标记 `allowInTerminal` 如 `` Ctrl + ` `` 除外）；macOS `⌘` 快捷键与 `Ctrl + Shift + ...` 组合照常生效。
- **模态隔离**：前景存在模态对话框时，仅允许该模态声明放行的命令（如 `settings`、`shortcuts`、`palette`），防止背后误切 Bot 或误切模式。
- **Bot 浏览器透传**：桌面端渲染进程将当前有效绑定白名单同步至 Electron 主进程（`ds-bot:sync-shortcuts`）；`BotViews` 的 `before-input-event` 仅拦截精确匹配该白名单的 `keyDown` 并转发回主窗口（`ds-bot:shortcut`），不误伤网页原生快捷键。

### 4. 插件版协作

插件版（跑在 DSH 网页前端中）将核心 DS Bot 命令（切换模式、收件箱、Bot 浏览器、群搜索、切对话 1–9）直接注册进 DSH 的 `ctx.shortcuts` 目录，由 DSH 统一管理，不重复渲染第二套自定义存储。

## 不做什么

- 不跨设备同步自定义快捷键：macOS 与 Windows/Linux 键位习惯不同，覆盖项留在当前设备。
- 不拦截操作系统级全局热键（窗口未聚焦时不劫持其他应用的按键）。
- 不支持多步和弦序列（如 `⌘K ⌘S`），保持单组合键直观可控。

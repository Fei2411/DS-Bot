# 统一审批代审

关联：#1299。第一版在现有 approval/request 上增加可选模型审核。

## 用户设置

团队设置的审批模型复用已配置的模型 API，默认跟随团队默认模型，允许单独指定。「替我审批」是现有权限选择器中的互斥模式，与只读、工作区、完全权限并列；这些设置由用户修改。群设置统一权限时使用群模式，否则继承成员 Bot 的模式。审核上下文独立，审核器没有工具。

## 执行

选择替我审批后，通过 DSH 的 setSandboxMode 和 ApprovalService.setPolicy 设置 workspace-write + ask。选择其他模式后应用该预设的沙箱与审批策略，并撤销进行中的模型审核。权限变更会停止受影响的外部 CLI 当前轮，保留会话记录，下一轮按新模式恢复。新会话沿用有效模式，子会话保留更窄的沙箱边界。旧版 autoApprove=true 迁移为 review 模式，false 与旧开关字段清除；群统一模式优先，否则继承成员模式。已保存的子会话原审批策略用于退出代审时恢复，旧会话策略在应用明确模式时清除。所有已进入 approval/request 的请求共用审核器，正式 guard 继续执行。

捕获 tools/pre-execute 的执行参数；插件自有请求用异步局部上下文绑定当前动作证据，区分同一脚本内的多次审批。审核读取所属私聊的近期事件或群的近期完整消息，区分直接用户消息和 Bot 转述。缺少用户原话、完整动作、模型配置，或输入超过审核预算时转人工。模型返回 allow、reject 或 manual；只有严格解析并完整结束的 allow 才允许当前一次。外部 CLI 只选择显式单次允许选项。

模型调用限时 30 秒。用户取消、手动回答、停用或更换配置后，迟到的模型答复失效。审核期间上下文变化或用户输入进入 inbox 时转人工；开始审核时仍有排队用户输入也转人工。私聊及其子会话保留宿主人工审批路径；子会话缺少宿主回答入口时安全结束请求。群及其子会话由 DS Bot 展示可操作的卡。最近 100 条审核结论、模型和脱敏理由保存在团队状态，界面按私聊或群筛选最近 20 条。

## 覆盖边界

本版处理已有的沙箱提权、目录授权、浏览器敏感动作、隐私外发及外部 Agent 权限请求。浏览器表单字段只描述页面上的名义提交，脚本可以拦截原生提交并改写请求，因此表单提交和页面写入点击统一交给人工；这类动作的模型自动批准需要能绑定实际请求目标与载荷的执行机制，本版尚未提供。文件动作带具体证据；下载分别记录发起站点和下载对象报告的实际来源 URL，来源含凭据、查询参数、片段或内联数据时转人工，并从模型证据中移除这些内容。其他无法描述完整效果或模糊删除目标的动作也交给人工。已有站点授权照常生效，支付及其他硬拒绝照常阻止。

本版保持已有触发规则。普通权限内的危险命令、PTC 直接 Node 副作用、MCP 副作用检测，以及邮件卡和电脑应用准入迁入统一审批链，是后续独立工作。外部 CLI 自己不产生的权限请求也不会被凭空补出。问答与用户接管保持各自流程。

## 检查

覆盖严格 JSON、完整动作证据、单次批准、拒绝、人工回退、取消与迟到结果、配置变化、用户新限制、群消息来源、子会话归属及权限恢复。使用隔离 mock 环境运行仓库 smoke；真实模型判断质量与各外部 CLI 的实际权限提示行为不以 mock 结果代替。

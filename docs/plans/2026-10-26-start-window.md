# 启动窗口：领航鲸

- 日期：2026-10-26 建立，2026-11-22 按现行代码整理
- 相关：[桌面应用](2026-10-16-desktop-app.md) · [桌面端安装与上手流程](2026-10-26-windows-onboarding.md) · [启动页文案](2026-10-29-start-copy.md)
- 代码：`app/src/start/`（`start.html`、`start.css`、`start.js`、`whale.js`、`text.mjs`）、`app/src/start-window.mjs`、`app/src/start-frame.mjs`、`app/scripts/start-assets.mjs`

## 为什么

引擎冷启动通常需要数秒至十余秒，本地启动页与 `http://127.0.0.1` 引擎页面跨源无法在同一窗口无缝过渡。单独的启动窗口能在双击后 1 秒内出现，借 Main Bot 的鲸鱼形象与真实阶段进度让等待可见、可解释，并在出错时提供恢复入口。

## 已定的行为

### 1. 双窗口与交接

- **启动窗口**：固定内容区 `720 × 540`（低矮屏幕工作区为 `720 × 500`），不可缩放或最大化，无边框 40px 可拖动标题带（Windows 11 启用 Mica，macOS 启用侧栏 vibrancy），在光标所在显示器居中显示。
- **主窗口**：在后台按最终尺寸（默认 `1320 × 860`）隐藏创建；引擎启动就绪（导入卡等待回答期间暂缓加载页面）且前端调用 `dsBotApp.ready()` 后，两窗口在原位交叉淡化，鲸鱼交接至团队侧栏的 Main Bot 头像位置，随后销毁启动窗口。启动窗口在交接期间保持固定尺寸不放大。
- 交接前关闭启动窗口直接退出应用并安全中止引擎或导入复制；换数据位置期间隐藏主窗口并用启动窗口显示搬迁状态。

### 2. 视觉布局与阶段进度

- 中心由 **112px 鲸鱼**、**水线与涟漪**以及**分段圆环**组成，顺利启动时默认不显示多余文字：
  - 默认三段弧顺时针对应三个真实阶段：**准备数据文件夹 → 启动本机引擎 → 打开团队**。
  - 选择从 DSH 复制旧团队后，圆环弹簧变形为四段，插入**复制以前的团队**阶段并按真实检查/字节进度填充。
- 阶段仅在等待满 250ms 后进入「进行中」状态（弧线流光 + 对应小道具动画），避免瞬时闪烁；完成后弧线顺时针画满。
- 底部居中位置行仅在首次启动空间不足或后续启动磁盘剩余空间跌破初始值 20% 时出现，提供「换个位置…」入口。

### 3. 鲸鱼状态、交互与节奏

- 鲸鱼根据真实阶段与耗时切换动作：浮出水面 → 准备数据（左右探视）→ 启动引擎（上下晃动）→ 满 10 秒放慢循环 → 满 45 秒切换为思考动作 → 打开团队（前冲）→ 就绪（庆祝喷水并跃入主窗口头像，或后续启动直接轻跃）。
- 点击鲸鱼触发喷水反馈（连续点击 4 次触发大水柱）；卡片等待用户选择时呼吸、眨眼并在正常/活泼档支持轻度探身与抚摸。
- 动画强度跟随团队保存在壳数据中的设置（安静 / 正常 / 活泼）并遵守系统 `prefers-reduced-motion: reduce`。

### 4. 页内卡片、超时与失败恢复

- 推荐盘、自定义目录确认、目录拒绝、团队导入、空间不足、DSH 占用等待、新版本对话拦截、180 秒启动超时与启动失败全部在启动窗口下方纸面以同一套弹簧变形卡片展示，不弹系统错误框。
- 卡片出现时圆环与鲸鱼组同步缩小上移，收起后复位；卡片文案严格遵循 [启动页文案](2026-10-29-start-copy.md)。
- 失败与超时卡始终提供**重试**、**复制详细信息**（脱敏环境信息 + 末尾 200 行日志）、**保存日志…**（脱敏末尾 5000 行）以及可展开的「详细信息」日志区；若后台更新器检测到新版本，卡内直接展示更新下载条。

### 5. 安全与无障碍

- 启动页为纯 DOM 实现（CSP `default-src 'self'`），仅向精确匹配的启动页路径暴露 `dsBotStart` 预加载桥。
- 鲸鱼与圆环设 `aria-hidden`，阶段状态同步输出至隐藏的无障碍进度列表（`aria-current="step"`）与礼貌朗读区，卡片出现时自动聚焦主按钮。

## 不做什么

- 不播放脱离真实阶段的假进度条。
- 不在启动窗口内嵌入第三方网页或账号登录子窗口（授权链接交由系统浏览器处理）。

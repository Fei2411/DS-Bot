# DS Bot UI 设计标准

适用于 `ds-bot/src/client/` 中的全部界面（基于 `v0.3.10` 实现整理并作为活标准维护）。

## 0. 使用方式与自动化门禁

- **等级**：「必须」不能违反；「应该」默认照做，有理由可以例外并在代码注释说明；「可以」是推荐做法。
- **标杆界面**：顶部胶囊（灵动岛）与设置页用量视图。新表面的变形与动效手感以这两处为准。
- **自动化检查**：`npm test` 会校验 `src/client/` 中的颜色变量（`--bt-*`）、圆角档位和弹簧常量，历史豁免记录在 `ds-bot/test/style-debt.json`（只减不增；清掉一处后运行 `node scripts/style-debt.mjs --write` 更新）。`npm run lint` 在 `src/client/**/*.js` 强制执行 `react/rules-of-hooks` 规则，防止浮层与设置页出现 Hook 顺序崩溃。
- **浮层隔离**：全局弹层与设置对话框由可复位的 `OverlayBoundary` 包裹，捕获异常后安全关闭出问题的浮层并弹出 toast，在下次打开或目标切换时复位，避免拖垮主聊天页。
- **原创与多语言**：只用原创图形与自绘图标；界面源文案写英文，多语言翻译在 `i18n.js` 与 `locales/`（共 8 种语言：英、简中、繁中、日、韩、西、法、德）。

## 1. 设计原则

1. **一个表面在变形。** 状态切换时让同一个表面改变尺寸和内容，而不是一个元素突然消失、另一个突然出现。
2. **形状只用弹簧。** 尺寸、位置、圆角的变化必须使用第 9 节的弹簧常量；只有颜色与透明度使用固定时长。
3. **有进就有出。** 弹出层、对话框、菜单关闭时必须播放退场动画（`useLinger`），不直接卸载。
4. **没事就安静。** 头像和界面只在状态变化或用户交互时动；空闲环境动画只在头像「活泼」档出现。
5. **内容等表面到位。** 表面变形期间内部内容不重排，大块内容在到位后再渲染。
6. **文案只写用户需要的信息。** 不写开发讨论、实现过程或未落地计划（见第 11 节）。
7. **颜色全部来自主题。** 组件不硬编码色值（见第 2 节）。

## 2. 颜色

### 2.1 主题

每个主题为浅色和深色各定义 8 个基础色，所有 `--bt-*` 变量由 `themes.js` 的 `themeVars()` 推导：

| 基础色 | 含义 |
|---|---|
| `bg` | 主区背景 |
| `sidebar` | 侧栏、设置导航背景 |
| `bubble` | Bot 消息气泡 |
| `card` | 卡片、输入框、弹出卡 |
| `text` | 正文 |
| `user` / `userText` | 用户气泡和它的文字 |
| `accent` | 强调色 |

内置主题：

| 主题 | 浅色 bg / text / accent | 深色 bg / text / accent |
|---|---|---|
| DeepSeek（默认） | `#fcfcfc` / `#141414` / `#4d6bfe` | `#141414` / `#f2f2f2` / `#5b7bff` |
| Mono | `#ffffff` / `#0d0d0d` / `#0d0d0d` | `#0f0f0f` / `#f4f4f4` / `#f4f4f4` |
| Paper | `#faf9f5` / `#1f1e1b` / `#d97757` | `#1f1e1b` / `#f3f0e8` / `#e08a6d` |
| Moonlight | `#f7f9fc` / `#121826` / `#1e86ff` | `#0b1020` / `#e8edf7` / `#4f9dff` |

用户可在 **设置 → 外观** 覆盖强调色（7 种预设或自选色）。预设色在浅色用 `INKS[ink][0]`、深色用 `INKS[ink][1]`；自选色在深浅模式同值。深色模式由宿主在 `body` 上标 `data-ds-dark-theme`。

### 2.2 语义变量

组件必须只使用以下变量：

| 变量 | 推导 | 用途 |
|---|---|---|
| `--bt-ink` | `text` | 正文、图标 |
| `--bt-ink-2` | `text` 60% | 次要文字、说明、默认图标 |
| `--bt-ink-3` | `text` 36% | 弱文字、占位、空状态 |
| `--bt-main` | `bg` | 主区、菜单、对话框背景 |
| `--bt-sidebar` | `sidebar` | 侧栏、设置导航；徽标描边 |
| `--bt-card` | `card` | 卡片、输入框 |
| `--bt-bubble` | `bubble` | Bot 气泡 |
| `--bt-line` | `text` 8% | 卡片、输入框边框（1px），分隔线 |
| `--bt-line-2` | `text` 15% | 浮起表面的发丝边（.5px） |
| `--bt-hover` | 浅色 `rgba(119,119,119,.09)`，深色 `rgba(160,160,160,.12)` | 悬停底色；次按钮底色 |
| `--bt-active` | 浅色 `.17`，深色 `.2` | 选中、按下底色 |
| `--bt-accent` / `--bt-accent-ink` | `accent`；字色在 `#141414` 与白色中取对比度更高者 | 主按钮、开关、焦点环、未读点、「New」分隔线、新消息胶囊 |
| `--bt-user` / `--bt-user-ink` | `user` / `userText` | 用户气泡 |
| `--bt-tag-bg` / `--bt-tag-ink` | `text` 6%（深色 9%） / 58% | 标签 |

### 2.3 状态色

| 状态 | 变量 | 用途 |
|---|---|---|
| 强调 | `--bt-accent` | 主操作、选中、焦点 |
| 成功 / 工作中 | `--bt-green`（`#00c972`） | 工作中徽标、完成对勾 |
| 主 Bot / 待处理 | `--bt-star`（`#ff9800`） | 主 Bot 星标、等你回答 / 待审批提示点 |
| 危险 | `--bt-danger`（`#e02135`） | 删除、错误文字、确认态底色（`color-mix` 10%） |
| 警告 | `--bt-warn`（浅色 `#8a5a00`，深色 `#f0b84a`） | 需要注意的警告提示 |

状态徽标底色与侧栏底色混合约 80%（`color-mix(in srgb, <色> 80%, var(--bt-sidebar))`）。

### 2.4 角色色

Bot 形象色定义在 `inks.js`（均含浅色、深色双值）：
- 形象可选 12 色：`black`、`brown`、`red`、`orange`、`yellow`、`green`、`cyan`、`blue`、`violet`、`magenta`、`gray`，外加渐变 `aurora`。
- 强调色预设 7 色：`deepseek`、`charcoal`、`graphite`、`rose`、`sky`、`tangerine`、`cobalt`。
- 未选颜色的新 Bot 从去掉 `black`、`gray`、`brown` 和渐变后的颜色中按 Bot id 确定性地选取；首个 Main Bot 默认为 `deepseek` 蓝鲸鱼。

### 2.5 颜色规则

- 必须：新增语义色先加进 `themeVars()`，再在组件中引用变量，不新增硬编码色值。
- 应该：一屏内大面积强调色不超过两处；浮起表面用 `.5px var(--bt-line-2)` 发丝边，平面卡片和输入框用 `1px var(--bt-line)`。

## 3. 字体

### 3.1 字族

- 界面：`var(--bt-font)`（跟随 `--dsw-font-family`，回退 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`）。
- 代码、密钥、路径：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。
- 对话正文跟随 `--dsh-content-font-size`（默认 14px）。
- 桌面应用通过 `app/src/fonts.css` 移除硬编码中文字体名，中文交由操作系统原生回退。

### 3.2 字号档

| 档 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 图表 | 10 / 12 | 400 | 用量热力图等图表刻度 |
| 注释 | 11 / 16 | 400–500 | 计数、时间、小芯片（`.bt-chip`） |
| 小 | 12 / 16 | 400–500 | 标签、说明、小按钮、报错（`.bt-tag`、`.bt-note`、`.bt-soft-sm`） |
| 正文 | 13 / 18 | 400 | 设置行、菜单项、面板正文、列表 |
| 内容 | 14 / 22 | 400 | 输入框、主按钮（`.bt-soft`） |
| 气泡 | 14 / 24 | 400 | 对话正文（行高随 `--dsh-content-font-size` 联动） |
| 胶囊 | 14 / 20 | 400 | 顶部胶囊（`.bt-pill`） |
| 小标题 | 15 / 20 | 600 | 对话框标题、卡片标题 |
| 标题 | 17 / 24 | 500 | 详情面板 Bot 名 |
| 数字 | 22 / 34 | 600 | 用量页大数字（搭配 `font-variant-numeric: tabular-nums`） |

字重只用 `400`、`500`、`600`；分区标题 `13 / 600`。

## 4. 间距与尺寸

### 4.1 间距

以 4px 为基数，允许 2 和 6 作为半步：

| 值 | 用途 |
|---|---|
| 2 | 同组按钮、列表行、菜单项之间 |
| 4 | 紧凑图标与文字之间 |
| 6 | 标签与字段、菜单内边距 |
| 8 | 常规组内间距、图标与文字 |
| 10 / 12 | 卡片内边距、设置行内边距（10 × 12） |
| 16 | 对话框内边距、面板边距 |
| 20 / 24 | 分区之间 |

### 4.2 控件高度

| 高度 | 控件 |
|---|---|
| 20 | 开关 |
| 28 | 小按钮、图标按钮、发送键 |
| 32 | 紧凑输入框、标签条项 |
| 36 | 标准按钮、圆形按钮、输入框、侧栏行头像 |
| 40 | 顶部胶囊、大号主按钮 |
| 44 | 输入框卡片最小高度、右侧面板标签条 |

可点击区域必须不小于 `28 × 28`。

### 4.3 布局尺寸

| 区域 | 尺寸 |
|---|---|
| 设置对话框 | 宽 `min(1100px, 100vw - 48px)`，高 `min(780px, …)`，各页统一尺寸；左侧导航 212px；窄屏全屏并切为概览列表与返回导航 |
| 记忆对话框 | 宽 `min(680px, 100vw - 48px)`，高 `min(760px, …)` |
| 右侧面板 | 详情 320px；浏览器默认 520px（可拖动，最小 360px），对话列至少保留 420px |
| 左侧栏 | 可拖右边缘调宽 264–420px；拖至 176px 以下吸附成 88px 头像窄栏（头像 44px）；支持整列收起；窄窗优先收右侧面板、再缩窄栏。桌面应用最小宽 508px |
| 气泡 | Bot 气泡最宽 `min(var(--bt-msg-w) × 100%, 100% - 82px)`（无悬停触屏设备不预留 82px）；用户气泡最宽 `var(--bt-msg-w) × 100%`（默认 80%，50%–100% 可调） |
| 输入框卡片 | 最宽 `min(992px, 100%)` |
| 主 Bot 卡片 | 宽 95px |

### 4.4 头像尺寸

`20`（密钥卡）· `22`（消息旁、搜索结果）· `24`（顶部胶囊、命令面板）· `28`（设置列表、动作行）· `36`（侧栏行）· `40`（设置概览）· `48`（浏览器空状态）· `60`（侧栏主 Bot 卡片）· `64`（详情面板）。

| 值 | 用途 |
|---|---|
| 4 | 标签、芯片 |
| 6 | 菜单项、迷你按钮 |
| 8 | 输入框、下拉框、分段按钮项 |
| 10 | 分段控件外框、侧栏行 |
| 12 | 卡片、菜单、主 Bot 卡片、Toast、命令面板、设置卡片 |
| 16 | 通用对话框 |
| 18 | 气泡 |
| 20 | 设置、记忆对话框 |
| 22 | 输入框卡片（多行或带附件时 18） |
| 999px | 胶囊形：标准按钮、标签页、顶部胶囊、开关 |
| 50% | 圆形：头像、圆形按钮、徽标、色块 |

## 6. 阴影与层级

### 6.1 高度档

| 档 | 阴影 | 边 | 用途 |
|---|---|---|---|
| 0 平面 | 无 | `1px var(--bt-line)` | 卡片、输入框 |
| 1 浮起 | `0 2px 8px -1px rgba(0,0,0,.06), 0 1px 2px rgba(0,0,0,.04)` | `.5px var(--bt-line-2)` | 顶部胶囊、输入框卡片 |
| 2 弹出 | `0 10px 20px -3px rgba(0,0,0,.1), 0 4px 6px -4px rgba(0,0,0,.1)` | `.5px var(--bt-line-2)` | 菜单、下拉、弹出卡 |

### 6.2 z-index

`0–8` 页面局部叠放 · `30` 顶部胶囊通知 · `40` 右侧面板 · `45` 拖动遮挡层与侧栏弹出窗格 · `60` 菜单、设置对话框、表情条、更新卡片 · `61` 记忆对话框 · `70` 头像编辑器、提示气泡、命令面板 · `1000` Toast。

## 7. 图标

- 必须使用 `icons.js` 中的自绘描边图标（`viewBox="0 0 20 20"`、`stroke="currentColor"`、圆头圆角），不复制其他产品图标；官方 `FishLogo` 仅表示 DSH Agent。连接第三方本地 Agent CLI 时仅用其官方 logo 并在 `NOTICE` 登记。
- 线宽：15px 图标 1.5；16–18px 图标 1.6；箭头可用 1.8。尺寸：行内/菜单 14–15px，按钮 16px，主操作 18px。

## 8. Bot 形象与动画

- **原创形象**：20 个三维描边形象由 `ds-bot/dev/characters.mjs` 生成进 `characters.js`（不手改数据）；支持用户上传自定义照片（进入可复用头像库 `bot/avatars/`）。
- **徽标**：右下角圆形徽标直径 12px（工作中 8px），`1.5px` 侧栏底色描边 + `corner-shape: round`。工作中为绿点，等你批准 / 等你回答为琥珀色（`--bt-star`）；主 Bot 为实心星，群管理员为 `AdminStar`。详情面板与顶部胶囊大头像不显示徽标。
- **状态动作**：空闲（静止）、思考（歪头起伏 2.2s + 眯眼）、搜索（左右探 1s）、工作中（上下晃 1.6s + 眨眼）、发消息（前冲 1.1s）、等你回答（跳两下）、完成（压扁回弹 1.8s）。
- **头像动画三档**（**设置 → 外观**，`body[data-bt-motion]`）：
  - **安静**：仅状态动作。
  - **正常（默认）**：加悬停抚摸、点击转圈与眼睛跟随指针。
  - **活泼**：加空闲小动作（9 秒一轮，错开）与等你回答持续轻跳。
- **全局界面动效三档**（**设置 → 外观**，`effectsOf()`）：**标准**（`full`）、**精简**（`reduced`）、**无**（`off`）；`off` 等同于触发系统 `prefers-reduced-motion: reduce`。

## 9. 动效

### 9.1 弹簧常量（`motion.js`）

所有形状、位移与尺寸过渡必须使用 `motion.js` 中的导出常量（由 `npm test` 校验）：

| 常量 | 刚度 / 阻尼 | 用途 |
|---|---|---|
| `SPRING_SHAPE` | `400 / 31.2` | 表面变形、对话框、开关滑块 |
| `SPRING_TAP` | `900 / 48` | 按压缩放、弹出层入场 |
| `SPRING_LIST` | `484 / 35.2` | 列表重排 |
| `SPRING_STRETCH` | `320 / 20` | 拉长展开的表面（如顶部胶囊通知） |
| `SPRING_POP` | `500 / 22` | 小标记弹出（对勾、图标） |
| `SPRING_LEAD` / `SPRING_TRAIL` | `784 / 48.2` · `289 / 29.2` | `useGlide` 滑块前沿 / 后沿 |
| `SPRING_GLIDE` | `1000 / 63` | 侧栏行重排 |
| `QUICK_EDGES` | `900 / 51` · `400 / 34` | 键盘与指针跟随高亮 |

### 9.2 固定时长

仅用于颜色与透明度：`.12s ease`（悬停与边框）、`.16s`（退场淡出）、`.22s ease-out`（内容模糊淡入 `bt-veil-in` / 遮罩淡入）。

### 9.3 共用件与入退场

- 共用原语：`useGlide`、`Segmented`、`useFlip`、`useMorph`、`useLinger`、`stepMenuFocus`、`bt-veil-in`。
- 入退场：`bt-pop-drop` / `bt-pop-lift` → `bt-pop-out`（菜单与下拉）；`bt-dialog-rise` → `bt-dialog-sink`（对话框）。关键帧仅操作独立 `translate` / `scale`，不覆盖 `transform`。

### 9.4 性能与减少动态效果

- 逐帧动画仅动合成属性（`transform`、`translate`、`scale`、`rotate`、`opacity`）。
- 无限循环动画（头像状态、扫光文字等）由 `motion-rest.js`（`installMotionRest`）通过 `document.getAnimations()` 与 `IntersectionObserver` 统一管理：页面隐藏、窗口 30 秒无输入或元素离开视口时自动暂停，恢复可见或有交互时继续。
- 避免给大面积整页加模糊，避免在流式渲染路径引入重排选择器（如大范围 `:has()`）。
- JS 动画启动前必须检查 `reducedMotion()` / `reducedEffects()`。

## 10. 核心组件规格

- **按钮**：主按钮 `.bt-send`（高 40 / 小号 28，胶囊，强调色底）、次按钮 `.bt-soft` / `.bt-soft-sm`（高 36 / 28，`--bt-hover` 底）、圆形 `.bt-round`（36 × 36）、图标 `.bt-icon-btn`（28 × 28）、迷你 `.bt-mini`（12px，圆角 6）。危险操作用 `--bt-danger`，放菜单末尾并加分隔线，不可逆操作需二次确认。
- **输入与选择**：`.bt-input`（高 36，圆角 8）、`.bt-select`（高 34，圆角 8）、`.bt-input-area`（最小高 80）、`Segmented`（2–4 互斥项）、`.bt-switch`（36 × 20 开关）、`.bt-swatch`（22 × 22 色块）。
- **菜单**：`.bt-menu`（圆角 12，最小宽 200，第 2 档阴影），`Esc` 关闭，支持 `stepMenuFocus` 键盘导航。
- **设置总控台**（详见 [设置总控台](../plans/2026-11-22-settings-console.md)）：左侧 212px 分组导航 + 顶部搜索触发（`⌘K` / `Ctrl+K` 唤起 `SettingsPalette`）；默认打开 **Overview** 概览页；多子页大类在同一滚动页内以顶部锚点跳转；**Appearance** 带实时预览；页内统一采用「分区标题 `h3` + `.bt-set-card` + `.bt-set-row`」结构。
- **连接器页**：搜索 + 自定义入口 + 已连接计数，分类胶囊与两列网格卡片；未连接图标置灰，首次连接成功时褪色转彩、图标轻弹并掠过一道淡光（打开页面时已连接行不重复播动画）。
- **右侧面板**：详情（320px）与浏览器（默认 520px，可拖）共用右栏；顶部 44px 标签条配 `useGlide` 滑块，依次放 Bot 详情、任务标签、浏览器页签与侧边对话页签。
- **顶部胶囊（灵动岛）**：高 40 胶囊，承载当前会话身份、记忆更新通知、后台任务进度与待审批/追问展开（支持卡片左右切换）。
- **侧栏**：支持折叠分组（微缩角色簇与待处理状态透出）、拖拽归组、88px 窄栏吸附与置顶图钉；无单 Bot 会话切换列表。
- **对话与反馈**：气泡圆角 18、输入框最小高 44 圆角 22、动作行高 36、长回复阅读胶囊 `.bt-reading` 高 28；报错按位置分流为行内 `.bt-error`、全局 `.bt-toast` 与空状态 `.bt-empty`。

## 11. 文案与多语言

- **必须**：只写用户需要的信息，不把内部讨论、计划或过程词（「马上」「下个版本」）写进界面。
- **必须**：设置项默认不加说明文字；确有必要时只写一句中性功能描述，不比较选项。
- **必须**：源文案写英文（sentence case，标签和按钮不加句号，按钮动词开头），通过 `t()` 查表；所有新增英文源文案需同步维护 `i18n.js` 与 `locales/` 下的 8 种语言（英、简中、繁中、日、韩、西、法、德）。
- **统一术语**：`Bot` → `Bot` · `Main Bot` → `主 Bot` · `Group chat` → `群聊` · `Group admin` → `群管理员` · `DSH Agent` → `DSH Agent` · `Memory` → `记忆` · `Connectors` → `连接器` · `Scheduled tasks` → `定时任务` · `Usage` → `用量`。

## 12. 可访问性

- 必须：图标按钮具 `aria-label`；菜单 `role="menu"`，对话框 `role="dialog"` + `aria-modal`，开关 `role="switch"` + `aria-checked`，分段控件 `role="group"` + `aria-pressed`。
- 必须：`Esc` 关闭最上层浮层，`Tab` 顺序与视觉一致，可聚焦控件在 `:focus-visible` 显示 `2px solid var(--bt-accent)` 焦点环。
- 必须：强调色上的文字和图标一律使用 `--bt-accent-ink`，并遵守 `reducedMotion()`。

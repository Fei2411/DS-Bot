# Bot 市场

- 日期：2026-11-12
- 相关：无对应 Issue。这是一份提案：先确认方向，再按方向拆实现。

## 为什么

现在一个 Bot 只活在自己的团队里。用户把提示词、角色、形象、建议模型和权限调到位以后，没有地方把它交出去；另一个人想用同样的做法，只能照着截图重新抄一遍。

市场要解决的就是这一件事：**把「一个人调好的 Bot」变成「另一个人能一键接入的 Bot」**，并且接入以后仍然是他自己的 Bot。

这里的取舍是：市场不是云端的 Bot 托管，也不是「大家共用一个 Bot」。Bot 的数据（记忆、会话、工作文件夹）都留在各自的电脑上，市场只分发「配置」，接入是在本地新建一份副本。这样才和现在的隐私 Bot、工作文件夹、权限模型对得上，也不用为了市场先把用户数据搬上服务器。

## 已定的行为

### 市场页

- 市场页默认就是可以逛的：打开就有分类、本周精选和「大家都在用」，不要求先登录、先配置、先接入任何东西。
- 卡片上必须有：形象、名字、角色（一句话）、两行说明、三个标签、作者、接入数、「接入」按钮。卡片的缩略图不需要作者上传：没有图片时按 Bot id 派生形状和墨色（`characters.js` 里已有的机制，FNV-1a + mulberry32，跨设备一致）。
- 左侧分类和来源（本周精选 / 官方出品 / 只在本机跑）是可点的筛选，点一次筛选，再点一次取消。
- 搜索匹配名字、角色、标签和说明；一进入搜索就收起精选区。

### 详情页

- 详情页回答四件事：它干什么（例子对话）、它要什么权限、作者是谁、这一版改了什么。
- 右侧常驻接入卡片：建议模型、思考强度、记忆处理方式、版本、是否已接入。
- 已接入的 Bot 在列表和卡片上显示「已接入」，再点接入会被拦下并提示已经接入过。

### 接入

- 接入 = 在用户自己的团队里**新建一个 Bot**，复制名字、角色、提示词、形象、建议模型和思考强度；作者的工作文件夹、记忆和会话都不会跟过来。
- 可以有三种去处：个人空间、工作空间（某个分组）、群聊。**隐私 Bot 只能进个人空间**，另两项禁用并说明原因（依据 `docs/plans/2026-10-27-private-bots.md`：隐私 Bot 不能被复制、不能加入群聊）。
- 权限先按作者声明的预设建，再以接入者本人的身份逐项收回；用户自己改权限不需要额外授权，因为那是他改自己的 Bot。收回是可逆的，界面上「收回」和「保留」互相切换。
- 接入时要选怎么跟作者保持同步：拿这一版之后自己走，或跟随作者更新。跟随只在作者发布新版本时提示，不会自动改用户的提示词。

### 更新

- 作者发新版本后，已接入的 Bot 出现「有更新」。「看改动」按段落对比提示词：对比按空行切段，用户自己改过的段落不会被覆盖；同一段双方都改过时不算冲突，会停下来让用户逐条选。
- 采纳是逐条的：用户勾哪几条就采纳哪几条，没勾的保持原样。
- 还没接入的 Bot 也能看「这版改了什么」，但只有只读预览，没有「你的副本」也没有勾选。

### 发布

- 发布只多问三样：从哪儿开始（从已有的 Bot 发 / 空白新建 / 导入包）、形象与文案（名字 40 字、一句话 24 字、卡片说明两行）、权限自检（勾选它需要什么，同时自动扫描硬编码密钥、作者的绝对路径、把作者记忆写进提示词、敏感动作）。
- 形象不用做封面图：从 20 个自带形状里挑 + 19 个墨色。
- 发布是**另存一份**：作者自己那个 Bot 的名字、记忆、文件夹一样不动，之后在本地改提示词也不会同步上去；要更新市场版本得重新发一次。
- 提交后走人审：能不能用、有没有夹带别人的数据、权限写得准不准。

### 我的接入

- 一屏看清三件事：装在哪、现在能不能用、作者这一版改了什么。
- 能按全部 / 运行中 / 有更新筛选；能暂停、恢复、打开；收回的权限在行内写明收回了哪几项。

## 不做什么

- 不做云端托管：没有「在市场里直接和别人的 Bot 聊天」，Bot 只在接入者的电脑上跑。
- 不做「大家共用一个 Bot」：接入一律是独立副本，记忆和文件夹各自新建。多人协作走群聊，不靠共享一个 Bot。
- 不改 DSH：市场是独立页面 + 插件侧的新建/更新调用，不动 DSH 本身。
- 不在这一版做：计费与付费 Bot、评分与评论、举报与下架流程、搜索结果排序权重、收藏夹、`.dsbot` 包的签名校验。

## 已知限制

- **「接入 = 独立副本」这个前提没有被真实用户验证过**。如果多数人其实想要「大家一起用一个 Bot」，记忆和权限模型要重做。
- 段落级对比只对「整块提示词字符串」做空行切分。作者如果把一段写成一整行，或者把整篇提示词当一段，对比就会退化成整块覆盖 / 整块保留。
- 隐私 Bot 不能被复制这条来自现有源码（`ds-bot/src/host/roster.js:342`），所以市场里隐私 Bot 只能进个人空间；如果以后允许「隐私 Bot 的公开版本」，要先改这条规则。
- 权限预设是 DSH 的整套 preset，不是逐项开关。界面上逐项「收回」在实现上要么落成一组 preset 变体，要么落成一个额外的拒绝清单，两者都需要先和 DSH 侧对齐——这一点没有验证。
- 卡片上的接入数、作者名、版本时间在原型里全是虚构数据，只用来撑密度和排序。
- 页面是按桌面和 390px 手机两档做的；平板 820px 能用但没专门打磨。
- 只做了浅色和深色两套配色，都取自 `docs/design/ui-standard.md` 的 8 个基础色与深色变体；没有验证嵌进 DSH 宿主里的效果。
